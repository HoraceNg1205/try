# COMP3111 Project

## Project Overview
A Library Management System designed for HKUST to manage library operations efficiently. The system serves three main user roles: Students/Staff, Authors, and Librarians with specialized functionalities for each user type.

## System Features

👨‍🎓 For Students/Staff

- User Authentication: Secure registration and login system

- Book Discovery: Browse and search available books in the library

- Borrowing System: Borrow and return books with due date tracking

- Digital Reading: Read books online through the platform

- Profile Management: Update personal information and preferences

- Borrowing History: Track past and current borrowed items

✍️ For Authors
- Author Portal: Specialized registration and login for authors

- Content Management: Upload, view, modify, and delete books

- Publication Tools: Add new books with detailed metadata

- Analytics Dashboard: View book statistics and reader engagement

- Profile Management: Maintain author profile and bibliography

👨‍💼 For Librarians
- Admin Access: Secure librarian registration and login

- Inventory Management: Comprehensive book catalog management

- User Administration: Manage student, staff, and author accounts

- System Oversight: Monitor library operations and usage statistics

- Profile Management: Update librarian account details
